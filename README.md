# habitbalance-site

Marketing and legal pages for [HabitBalance](https://habitbalance.unkinddragon.com) —
a private, no-account habit tracker for iPhone.

- `index.html` — landing page (features, pricing)
- `privacy.html` — privacy policy (required by App Store Connect)
- `support.html` — support page + FAQ

Served via GitHub Pages. Static HTML/CSS only — no build step, no cookies, no third-party
resources. Bug reports and support requests for the app are welcome in this repo's
[Issues](https://github.com/unkinddragon/habitbalance-site/issues).
